# 🪐 PLANET MERGE（惑星合体ゲーム）

HTML5 Canvas、Vanilla CSS、JavaScript、および **Matter.js** 2D物理エンジンで構築された、スイカゲーム風の宇宙テーマ惑星合体パズルゲームです。
天体を落として同じ天体同士を合体させ、月から太陽へと進化させてハイスコアを目指しましょう！

[English README (README.md)](README.md)

---

## 🌟 天体進化表（全10段階）

同じ天体同士を2つぶつけると、1段階上の天体へ進化します：

1. **月 (Moon)** - `+2 pt`（灰白色のクレーター模様）
2. **水星 (Mercury)** - `+4 pt`（グレーの岩石天体）
3. **火星 (Mars)** - `+8 pt`（赤色の錆びた外観）
4. **金星 (Venus)** - `+16 pt`（黄金色の大気模様）
5. **地球 (Earth)** - `+32 pt`（青い海と緑の大陸・大気ベール）
6. **海王星 (Neptune)** - `+64 pt`（濃いインディゴブルー）
7. **天王星 (Uranus)** - `+128 pt`（ターコイズブルーの氷天体）
8. **土星 (Saturn)** - `+256 pt`（奥側と手前側に分割描画された立体3Dリング）
9. **木星 (Jupiter)** - `+512 pt`（重厚な黄土色ベース、大気バンド、大赤斑）
10. **太陽 (Sun)** - `+1024 pt + 5000 BONUS`（16本の回転プラズマフレア、ファンファーレ音、花火爆発演出）

## ✨ 主な特徴

- **2D物理演算**: **Matter.js** を採用し、天体の転がり・衝突・反発・摩擦を自然にシミュレート。
- **カスタムHTML5 Canvas描画**: 3D光彩グラデーション、土星の立体リング描画、木星の黄土色大気模様、リアルタイム回転する太陽のフレアアニメーション。
- **合成効果音（Web Audio API）**: 外部音声ファイル不要で、落下音・合体音（レベル別の高音階）・太陽誕生ファンファーレ和音・ゲームオーバー音を生成。
- **レスポンシブ ＆ タッチ対応**: PCでのマウスドラッグ/クリック、スマートフォンでのタッチ操作（`touch-action: none`）に完全対応。
- **インタラクティブ惑星進化表**: モーダル内で全10種類の天体の実際のゲーム内グラフィックがリアルタイムアニメーションで確認可能。
- **ハイスコア保存**: ブラウザの `localStorage` にベストスコアを自動記録。
