# 🪐 PLANET MERGE（惑星合体ゲーム）

HTML5 Canvas、Vanilla CSS、JavaScript、および **Matter.js** 2D物理エンジンで構築された、スイカゲーム風の宇宙テーマ惑星合体パズルゲームです。
天体を落として同じ天体同士を合体させ、月から太陽へと進化させてハイスコアを目指しましょう！

[English README (README.md)](README.md)

---

## 🌟 天体進化表（全11段階）

同じ天体同士を2つぶつけると、1段階上の天体へ進化します：

1. **冥王星 (Pluto)** - `+1 pt`（冷たい氷と茶褐色の岩石、ハート型氷原・クレーター模様）
2. **月 (Moon)** - `+2 pt`（灰白色のクレーター模様）
3. **水星 (Mercury)** - `+4 pt`（グレーの岩石天体）
4. **火星 (Mars)** - `+8 pt`（赤色の錆びた外観）
5. **金星 (Venus)** - `+16 pt`（黄金色の大気模様）
6. **地球 (Earth)** - `+32 pt`（青い海と緑の大陸・大気ベール）
7. **海王星 (Neptune)** - `+64 pt`（濃いインディゴブルー）
8. **天王星 (Uranus)** - `+128 pt`（ターコイズブルーの氷天体）
9. **土星 (Saturn)** - `+256 pt`（奥側と手前側に分割描画された立体3Dリング）
10. **木星 (Jupiter)** - `+512 pt`（重厚な黄土色ベース、大気バンド、大赤斑）
11. **太陽 (Sun)** - `+1024 pt + 5000 BONUS`（16本の回転プラズマフレア、コロナオーラ、ファンファーレ音、花火爆発演出）

## 🕳️ 太陽合体 ＆ ブラックホール・超新星大爆発（Black Hole & Supernova）

最高レベルの**太陽（Level 10）同士が合体**すると、ゲーム最大のスペクタクル演出である**ブラックホール出現シーケンス**が発動します！

1. **ブラックホールの覚醒**: 合体地点に純黒の暗黒核（事象の地平面）と高速回転する発光降着円盤、重力レンズ光彩を持つリアルなブラックホールが誕生。
2. **螺旋公転吸入（スパゲッティ化）**: 盤面上のすべての惑星が中心に向かって優雅に螺旋公転しながら引き寄せられ、サイズを縮小（スパゲッティ化）しながら次々に吸入消滅。
3. **特異点収縮**: 全惑星を飲み込むと、ブラックホールが中心へと極小特異点（半径 1.5px）まで高張力サウンドとともに急激に収縮。
4. **超新星大爆発（Supernova）**: 全画面ホワイトフラッシュとともに6重の多色超巨大ショックウェーブと300個以上の光粒花火が全方位へ炸裂！
5. **超特大ボーナス ＆ ゲーム継続**: `+15,000 pt`（＋吸入ボーナス）を獲得し、盤面がクリーンになった状態でそのままゲームがシームレスに継続されます。

> 💡 **テストモード（`?test`）**:  
> `index.html?test` にアクセスすると、最初から盤面底部に太陽や惑星が配置され、手元に太陽がセットされた状態からスタートするため、ブラックホール演出を即座にテストできます。

## ✨ 主な特徴

- **2D物理演算**: **Matter.js** を採用し、天体の転がり・衝突・反発・摩擦を自然にシミュレート。
- **ブラックホール＆超新星演出**: 太陽同士の合体による全惑星吸い込み、特異点収縮、超新星大爆発、および全消滅ボーナス。
- **連鎖コンボ＆スクリーンシェイク**: 短時間での連続合体によるコンボ倍率ボーナスと、合体衝撃に応じたダイナミックな画面揺れ。
- **カスタムHTML5 Canvas描画**: 3D光彩グラデーション、土星の立体リング描画、木星の黄土色大気模様、リアルタイム回転する太陽のフレア、ブラックホールの降着円盤。
- **合成効果音（Web Audio API）**: 外部音声ファイル不要で、落下音・合体音・太陽誕生ファンファーレ・ブラックホール重低音サブベース・超新星ファンファーレをリアルタイム生成。
- **多言語対応（日本語 / 英語）**: ブラウザ言語に応じた自動言語判定、およびヘッダーの「EN / JA」ボタンによるワンタップ切替。
- **レスポンシブ ＆ タッチ対応**: PCでのマウス操作、スマートフォンでのタッチ操作（`touch-action: none`）に完全対応。
- **インタラクティブ惑星進化表**: モーダル内で全11種類の天体の実際のゲーム内グラフィックがリアルタイムアニメーションで確認可能。
- **ハイスコア保存**: ブラウザの `localStorage` にベストスコアを自動記録。
- **GitHub Actions 自動デプロイ**: `v*` バージョンタグの push で GitHub Pages へ自動デプロイ。
